# ふわっちのオエッボタン

후와 미나토 비공식 팬 클립 사이트입니다. 기본은 별도의 구간 음성 파일을 재생하며, ‘영상 보기’로 유튜브 원본의 같은 구간을 펼칩니다. 전환 시 재생 위치를 이어가고 이전 재생 소스는 멈춥니다.

## 현재 샘플

샘플 2개의 음성은 직접 생성한 테스트용 효과음이며 실제 후와 보이스가 아닙니다. 영상은 YouTube 공식 API 예제 영상입니다. 실제 클립과 음성 파일로 교체해주세요.

## 클립 추가

‘목록 관리’에서 영상 주소, 방송명, 시작·종료 시간과 음성 경로를 입력하세요. 같은 영상의 클립은 자동으로 묶이며 시간순으로 번호가 매겨집니다.

음성은 해당 구간만 자른 파일을 준비합니다. 원본 구간이 12:35–12:42라면 음성 파일은 그 7초만 담고 있어야 합니다. 파일은 `audio/영상ID-001.mp3`와 같은 경로로 이 저장소에 업로드하고, 음성 경로에도 같은 값을 입력하세요. 공개 HTTPS 음성 주소도 사용할 수 있습니다. 음성 파일이 없을 때에는 영상 보기로 재생할 수 있습니다.

### 여러 구간 등록

위쪽 폼에 유튜브 주소와 방송명·날짜·카테고리를 입력하고 ‘한 방송의 여러 구간 한꺼번에 추가’를 펼치세요.

```text
12:35 / 12:42 / 첫 번째 오에엑 / audio/001.mp3
28:10 / 28:16 / 두 번째 오에엑 / audio/002.mp3
1:02:35 / 1:02:41 / 세 번째 오에엑 / audio/003.mp3
```

시작·종료는 필수이며 이름과 음성 경로는 생략할 수 있습니다. 구분자 `/` 양쪽에는 공백을 넣어주세요. ‘등록 내용 확인’을 누른 뒤 내용을 검토하고 추가합니다. 엑셀에서 탭으로 구분된 최대 4열을 복사해 붙여넣어도 됩니다.

## 공개 목록 업데이트

화면에서 편집한 내용은 해당 브라우저에만 저장됩니다. ‘목록 파일 저장’으로 받은 `clips.json`을 GitHub 저장소의 같은 파일과 교체하면 모든 방문자에게 반영됩니다. 음성 파일도 업로드해야 합니다. 기존에 편집한 브라우저에서 새 공개 목록이 안 보이면 ‘배포된 목록으로 되돌리기’를 누르세요. 기존 로컬 편집 내용은 초기화되므로 먼저 내보내 보관하는 것이 좋습니다.

즐겨찾기와 재생 기록은 각 방문자의 브라우저에 별도로 저장됩니다. 관리자 기능으로 서버 내용을 수정하는 구조가 아니므로 공개 페이지의 목록 관리는 다른 방문자의 목록이나 사이트를 바꾸지 않습니다.

## 재생

- 랜덤 재생: 현재 검색·연도·분류 결과에서 섞어 선택합니다.
- 랜덤 연속 재생: 현재 구간이 끝나면 다음 구간을 무작위로 재생합니다.
- 한 구간 반복: 동일한 구간을 반복합니다. 랜덤 연속 재생과 동시에 켜지지 않습니다.
- 이 방송의 클립 순서대로 재생: 화면에 표시된 해당 방송의 구간을 시간순으로 재생합니다.
- 듣기 중 영상 보기: 음성을 정지하고 같은 위치의 유튜브를 표시합니다.
- 영상에서 소리만 듣기: 유튜브를 정지하고 별도 음성 파일로 돌아갑니다. 유튜브를 숨긴 채 재생하지 않습니다.

음성 파일 제공 서버 설정이나 브라우저에 따라 탐색·자동 재생이 제한될 수 있습니다. 모바일에서 재생이 막히면 재생 버튼을 눌러주세요. 음성과 영상 간 전환에는 로딩이나 약간의 위치 오차가 생길 수 있습니다.

GitHub Pages는 main 브랜치의 루트에서 게시합니다. 빌드나 별도 설치는 필요하지 않습니다.
